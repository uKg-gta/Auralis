Sources & Licenses

Auralis plays music through official players and public catalogs. Availability and rights are set by rights holders. The MIT license covers Auralis code only; it does not grant rights to third-party music, videos, artwork, names, or metadata.

Local files

Imported audio and artwork stay in this browser. You are responsible for having the rights to the files you import.

Audius

Auralis searches Audius and streams the selected track from its public catalog. Auralis does not download or cache Audius audio. Track availability and rights remain with the artists.

Audius API · Audius Terms of Use

YouTube

YouTube search uses YouTube Data API v3. Videos play only in YouTube’s visible official embedded player with its controls and branding. Auralis does not extract, download, or cache YouTube audio or video, or play it in the background. Video availability and rights are set by YouTube and rights holders.

YouTube API developer policies · YouTube Terms of Service · Google Privacy Policy

Jamendo

Jamendo tracks are streamed from its public Creative Commons catalog. Each track has its own license; Auralis displays the artist credit, license, and Jamendo link. Jamendo API access is used only for this non-commercial prototype.

Jamendo API · Jamendo API Terms · Creative Commons licenses

MusicBrainz

MusicBrainz is used for metadata lookups only. It does not provide audio to Auralis. Metadata suggestions are shown for user confirmation before they are applied.

MusicBrainz API · Rate limits · Data license
