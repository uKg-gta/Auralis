# Third-party sources and content

The MIT license in this repository applies only to Auralis source code. It
does not grant rights to third-party music, videos, artwork, artist names or
metadata. Availability and use are governed by each provider and the relevant
rights holders.

- **Audius:** Catalog results and streams come from Audius. Track rights and
  availability remain with the artists. See the [Audius API documentation](https://docs.audius.co/api/)
  and [Audius Terms of Use](https://audius.co/documents/TermsOfUse.pdf).
- **YouTube:** Search results use YouTube Data API v3 and playback remains in
  the visible official YouTube player. Follow the [YouTube API developer policies](https://developers.google.com/youtube/terms/developer-policies)
  and [YouTube Terms of Service](https://www.youtube.com/t/terms). Google and
  YouTube may collect data as described in the [Google Privacy Policy](https://policies.google.com/privacy).
- **Jamendo:** Streamed catalog tracks are credited to their artists, display
  the track's Creative Commons license, and link to Jamendo. The API is used
  only for this non-commercial prototype. See [Jamendo API documentation](https://developer.jamendo.com/v3.0),
  [Jamendo API Terms of Use](https://devportal.jamendo.com/api_terms_of_use),
  and [Creative Commons licenses](https://creativecommons.org/licenses/).
- **MusicBrainz:** Optional factual metadata and artist release lookups only;
  Auralis does not obtain audio from MusicBrainz. See the [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API),
  [rate limits](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting),
  and [data license](https://musicbrainz.org/doc/About/Data_License).

Auralis plays music through official players and public catalogs. Availability
and rights are set by the rights holders. Auralis does not download or cache
Audius, YouTube or Jamendo audio or video.
